# PRD｜NEXT EPISODE 下一集 V1.0

## 产品定位
一款把塔罗变成人生连续剧的互动运势微信小程序。

## 目标用户
18-30 岁、小红书型年轻女性；对塔罗/星座/MBTI 不排斥，重视审美、共鸣和分享。

## 核心目标
验证“每日抽牌 → 今日剧情 → 分享 → 晚间回看 → 次日再来”的闭环。第一成功信号是用户主动晒结果。

## Core Loop
TODAY 未抽牌 → 抽一张今日牌 → 翻牌 → 今日牌结果 → 今日剧情 → 本集彩蛋 → 分享 → 晚间回看 → 明日关键词 → D1。

## P0
微信登录、Onboarding、TODAY、抽牌、今日牌结果、AI 今日剧情、今日信号、分享卡、Archive 基础、埋点。

## P1
彩蛋、晚间回看、明日关键词、当前章节、收藏、NEXT+。

## Non-goals
八字/星盘/黄历大杂烩、AI 大师聊天、金币等级、社区、恐吓付费、付费抽好牌。

## 验收
- 新用户 60 秒内完成第一次翻牌。
- TODAY 首屏唯一 Primary CTA 为抽牌。
- 剧情至少使用一个用户 focus。
- 两步以内生成分享图。
- 连续 7 天无明显模板重复。
