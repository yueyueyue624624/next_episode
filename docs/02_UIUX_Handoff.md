# UI/UX Handoff｜Fate Editorial

## 视觉方向
命运编辑部：时尚杂志 + Editorial 排版 + Tarot + Personal Issue。避免紫色星空、烟雾、水晶球与“大师感”。

## 基础 Token
- Paper #F4F0E8
- Ink #171717
- Secondary #55524D
- Line #D8D2C7
- 375×812；左右 20px
- 正文 15-17px；Meta 11-13px

## 一级导航
TODAY / ARCHIVE / ME。

## TODAY 状态
NOT_DRAWN → CARD_REVEALED → STORY_READY → ACTIVE_DAY → EVENING_REVIEW_AVAILABLE → ISSUE_CLOSED。

## 核心页面
TODAY、Draw、Tarot Result、Feature Story、Bonus、Evening Review、Archive、Me、Share Sheet。

## Share Templates
COVER / QUOTE / CARD；优先 1080×1350 4:5。

## 动效原则
仪式感来自节奏，不来自等待。Card Flip 350-500ms；避免长加载与魔法爆炸。
