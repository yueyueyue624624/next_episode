# Analytics / KPI / Experimentation

## North Star Signal
主动生成并分享结果，尤其形成小红书/朋友圈/聊天自然 UGC。

## Core Metrics
Onboarding Completion、Draw Start、Card Reveal、Story Open、Story Completion、Share Generate、Share Click、Evening Review、D1/D3、Fallback Rate。

## 早期目标
Share Card Generate Rate 15%+；D1 25-30%+。

## 主漏斗
进入 → Onboarding → Draw → Reveal → Story → Complete → Share Generate → Share。

## Retention Funnel
D0 Draw → Evening Review → Feedback → Tomorrow Teaser → D1 Return → Draw Again。

## A/B
首页 CTA、3 vs 5 张牌、分享 CTA、Editor Note 长度、晚间开放时间。实验用户固定 variant。
